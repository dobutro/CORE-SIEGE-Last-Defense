# CORE-SIEGE-Last-Defense

Футуристический Tower Defense прототип на Python с интерфейсом на PySide6 и игровым рендером через pygame.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Управление

- ЛКМ по клетке — установить выбранную башню.
- ЛКМ по башне — выбрать её для улучшения.
- Кнопка «Следующая волна» — запуск волны.
- Кнопка «Пауза» — остановить/продолжить бой.
